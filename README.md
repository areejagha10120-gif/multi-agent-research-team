# Multi-Agent Research Team

A modular research system built with CrewAI, Groq, and Streamlit.

## Agents

- Research Planner
- Web Researcher
- Fact Checker
- Source Analyst
- Research Synthesizer

## Stack

- CrewAI
- Groq
- GPT-OSS 120B
- Streamlit
- DDGS Web Search

## Workflow

User Question
→ Research Planning
→ Web Research
→ Fact Checking
→ Source Analysis
→ Final Synthesis

## Deployment

The application is designed for deployment on Streamlit Community Cloud.
